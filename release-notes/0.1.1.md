Quizzes that pass a live check 5 of 5 times, a planner audit, and flashcards Spaced Repetition can see.

**Fixed**
- A Lecture Companion lecture note (Slides / Summary / Transcript / My notes) was split into four topics, with "Transcript" the heaviest. It is now one topic named after the lecture, quizzed from its Summary.
- Quiz parsing: one-line `Q: … A: …`, label-only lines, `(1)` and `#1` numbering, code kept verbatim (no more `2**3` → `23`), list numbering inside answers kept, closing remarks dropped, an unclosed `<think>` tolerated; the plugin keeps the first N questions when the model writes more.
- Quiz prompt: only terms and methods the notes name, no asides, one unhedged result for calculations, no introduction or sign-off.
- Planner: `2026-02-30` is no longer a valid date; an exam today or in the past is refused; too many topics for too few days spread to the least-loaded day instead of piling on the last one; a rebuild after everything was learned no longer squeezes every review into the first days; headings with `#` keep their text.
- Flashcard exports start with `#flashcards/<Course>` so the Spaced Repetition plugin picks the note up (new setting *Flashcards tag*); `::` inside a card is escaped.
- Ollama errors say why a request failed (for example `ECONNRESET`) instead of "fetch failed".

**Measured**
- `npm run quiz:live` builds three lecture notes in Lecture Companion's real shape and runs the plugin's prompt, client and parser against `qwen3.5:9b`: with this release, 5 of 5 runs pass every check (count, answers present, topics named, no duplicates, no terms from outside the notes). 36 tests (was 24).
