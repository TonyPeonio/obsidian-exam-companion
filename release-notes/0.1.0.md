First release.

- **Plan an exam**: pick a course folder, an exam date and minutes per day; every `##` section of the course notes becomes a topic, each gets a first pass and a review 3–5 days later, and the last two days are mixed review. The plan is a checklist note under `Exams/`.
- **Today's quiz**: a local model (Ollama) writes questions on today's topics from the notes' own text, each with a collapsed answer and a link to the section it came from.
- **Record quiz results**: tick what you got right; topics with a wrong answer become weak topics and the remaining days are rebuilt with extra review. Past days are never touched.
- **Export flashcards**: every quiz question becomes a `Question::Answer` line for the Spaced Repetition plugin.
- Reads Lecture Companion's course notes as they are (`## YYYY-MM-DD` sections with a `### Summary`).
